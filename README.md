# نظام إدارة جودة الخرسانة الجاهزة (CQC) — حزمة PWA كاملة

## محتويات الحزمة
- `index.html`  — البرنامج
- `manifest.json` — بيانات التطبيق (الاسم، الأيقونات، الألوان)
- `sw.js` — يخزّن البرنامج ليفتح بدون إنترنت
- `icons/` — الأيقونات (192 / 512 / maskable / apple-touch)
- `.nojekyll` — يمنع معالجة جيت هوب للملفات

## النشر على GitHub Pages
1. فك الضغط ثم ارفع **كل الملفات والمجلد icons** في الجذر (root) للـ repository.
2. Settings ← Pages ← Deploy from a branch ← main ← /(root) ← Save.
3. افتح الرابط `https://USERNAME.github.io/REPO/` من كروم الموبايل: يظهر خيار «تثبيت التطبيق».

## تحويله إلى APK
1. افتح https://www.pwabuilder.com وضع رابط الموقع واضغط Start.
2. اضغط Package for stores ← Android ← Generate.
3. نزّل الملف المضغوط: فيه `.apk` للتجربة و`.aab` للمتجر، **وملف مفتاح التوقيع — احتفظ به ولا تفقده** (بدونه لا يمكنك تحديث التطبيق).

### لإخفاء شريط العنوان داخل التطبيق
يحتاج ملف `assetlinks.json` (يعطيك إياه PWABuilder) على **جذر الدومين**:
`https://USERNAME.github.io/.well-known/assetlinks.json`
وهذا ممكن فقط إذا سميت الـ repository باسم `USERNAME.github.io` (موقع المستخدم) أو استخدمت دومينًا خاصًا. في غير ذلك يعمل التطبيق لكن بشريط عنوان صغير.

## بعد أي تعديل على البرنامج
ارفع `index.html` الجديد بنفس الاسم. التحديث يصل للمستخدمين عند فتح البرنامج وهو متصل بالإنترنت.
